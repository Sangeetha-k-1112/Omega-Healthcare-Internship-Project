# Cancer Curation Application Using GenAI

## Overview

The Cancer Curation Application is a healthcare-focused web application designed to support the extraction, processing, validation, and management of cancer-related clinical information using Generative AI.

The application combines frontend interfaces, backend services, PostgreSQL database integration, REST APIs, and AI-based data processing to convert unstructured clinical information into structured data for cancer curation workflows.

## Key Features

- Processing of unstructured clinical information.
- AI-assisted extraction and processing of cancer-related information.
- Conversion of clinical information into structured data.
- Backend services for data retrieval and processing.
- PostgreSQL database integration.
- REST API-based communication between application components.
- Data review and validation through application interfaces.
- Curation tables, forms, dashboards, and data visualization.
- Support for generating structured reports.
