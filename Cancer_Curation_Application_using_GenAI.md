# Cancer Curation Application Using GenAI

## 1. Project Description

The Cancer Curation Application is a healthcare-focused application developed to support the extraction, processing, validation, and management of cancer-related clinical information using Generative AI.

The application combines frontend technologies, backend services, PostgreSQL database integration, REST APIs, and AI-assisted data processing to support cancer data curation workflows.

The project was developed during my Software Developer Internship at Omega Healthcare.

---

## 2. Problem Statement

Cancer-related information can be available in unstructured formats such as clinical notes, medical records, pathology reports, discharge summaries, and treatment records.

Traditional manual curation requires significant effort to review these records and identify relevant cancer-related information.

The project addresses challenges such as:

- Manual extraction of cancer-related information.
- Time-consuming data curation.
- Possibility of errors during manual data entry.
- Difficulty in processing large amounts of unstructured clinical information.
- Delays in preparing structured cancer-related data.
- Limited intelligent assistance during the curation process.

---

## 3. Objectives

The main objectives of the application are:

- Automate the extraction and structuring of cancer-related information.
- Support processing of unstructured clinical information.
- Provide a user-friendly interface for data entry, review, and management.
- Develop backend services for application and database operations.
- Use Generative AI to assist with cancer-related information processing.
- Provide structured information for review and validation.
- Support efficient cancer data curation workflows.

## 5. Application Workflow

The application follows a frontend-to-backend-to-database and AI-assisted processing workflow.

```text
User
  ↓
AngularJS Frontend
  ↓
REST API
  ↓
Backend Services
  ↓
Data Processing
  ↓
AI / Prediction Services
  ↓
PostgreSQL Database
  ↓
Structured Data
  ↓
Frontend
  ↓
Curation Tables / Forms / Dashboards / Reports
```

### Workflow Description

1. The user interacts with the AngularJS-based application interface.
2. The frontend sends requests to backend services through REST APIs.
3. The backend receives and processes the request.
4. Submitted clinical information can be passed through the appropriate data-processing or parsing component.
5. The processing component converts relevant information into structured data.
6. AI or prediction services can be used for AI-assisted processing.
7. The backend manages the processed information and database operations.
8. PostgreSQL is used for structured data storage and retrieval.
9. The backend returns structured JSON responses through REST APIs.
10. The frontend displays the processed information through application interfaces such as tables, forms, dashboards, and reports.
